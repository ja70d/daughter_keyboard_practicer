# 🎮 键盘练习游戏

一款面向一年级学生的在线打字练习游戏，支持**人教版一年级语文拼音**和**英语单词**两套教材内容。

> 🚀 **在线体验**：https://keyboard-game2.pages.dev

---

## ✨ 功能特性

### 🇨🇳 拼音模式
- 人教版一年级上册/下册教材内容（识字 → 课文）
- 实时反馈：正确变绿、错误变红，键盘同步点亮
- 音效系统：Web Audio API 合成，无需音频文件

### 🔤 英语模式
- 人教版一年级英语 Unit 1–8 全部单词
- 图片动画：emoji 弹入、成功彩虹光环、失败震动效果

### 🎯 两种出题模式
| 模式 | 说明 |
|------|------|
| 📖 顺序 | 按教材单元/课文顺序出题 |
| 🔀 混杂 | 随机打乱本关词汇 |

### 📝 两种练习模式
| 模式 | 输入框提示词行为 |
|------|-----------------|
| 📝 测验 | 提示词逐字符显现，考验记忆 |
| 💡 练习 | 提示词常亮显示，帮助熟悉键盘 |

### 🏆 关卡与进度
- **按教材单元圈定关卡**：每关对应一个单元/课文，词汇量按单元自动适配（4–6 个）
- 一关通关后自动进入下一关，所有单元练完循环回第一单元
- 实时显示得分、连击数、正确/错误数

## 🚀 快速开始

### 本地运行

项目是纯静态站点，不需要任何构建工具。任选一种方式：

```powershell
# 方式一：Python 内置服务器
python -m http.server 8080

# 方式二：Node.js http-server
npx http-server -p 8080
```

然后访问 http://localhost:8080

## 🏗️ 技术栈

| 类别 | 技术 |
|------|------|
| 语言 | 原生 JavaScript（无框架） |
| 样式 | 原生 CSS3（CSS 变量、动画、flex 布局） |

### 为什么不用框架？
- 项目规模小（~800 行 JS + ~600 行 CSS）
- 没有组件化/状态管理需求
- 零依赖、零构建、零服务器成本

## 📚 教材数据

数据直接嵌入在 `game.js` 中，每个词条包含：

```javascript
// 拼音示例
{ word: '天', pinyin: 'tian', hint: '蓝天白云', unit: '一年级上册·识字1' }

// 英语示例
{ word: 'hello', meaning: '你好', emoji: '👋', unit: 'Unit 1 Hello!' }
```

### 关卡划分逻辑

```javascript
// 按 unit 字段自动分组，每组 = 一关
第 1 关 → 一年级上册·识字1（6 词）
第 2 关 → 一年级上册·识字2（5 词）
第 3 关 → 一年级上册·识字3（5 词）
...
```

要扩充词汇，只需在对应 `PINYIN_DATA` / `ENGLISH_DATA` 数组里追加条目，带上正确的 `unit` 字段即可，关卡会自动调整。

## 🎮 游戏玩法

1. 进入页面默认从「第 1 关 · 拼音 · 测验」开始
2. 看到汉字（或英文释义）后，在虚拟键盘/物理键盘上拼写
3. 输入正确 → 字符变绿 + 键盘点亮 + 庆祝音效 + 连击 +1
4. 输入错误 → 字符变红 + 键盘震动 + 叹气音效 + 连击清零
5. 完成当前单元所有词汇 → 弹出结算弹窗 → 点「下一关」继续

## 🛠️ 自定义

### 添加/修改词汇

直接编辑 `game.js` 顶部的 `PINYIN_DATA` 或 `ENGLISH_DATA` 数组。

### 添加新科目（数学、自然...）

1. 在 HTML 里添加新的显示区（参照 `pinyin-mode` / `english-mode`）
2. 在 `game.js` 添加新的数据数组
3. 在 `showNextWord` / `handleInput` 里加对应分支

### 调整得分规则

找到 `handleInput` 里的 `gameState.score += 10 * gameState.combo`，修改系数即可。
